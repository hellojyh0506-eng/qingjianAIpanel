# 对话头像

学习助手「真实对话」标签里 A / B 两个角色的头像。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `avatar_a_boy.png` / `@2x` / `@3x` | 40 / 80 / 120 px | A 角色（左侧），按 DPI 缩放选图 |
| `avatar_b_girl.png` / `@2x` / `@3x` | 40 / 80 / 120 px | B 角色（右侧） |
| `*_512.png` | 512 px | 原图，以后重新导出用 |

- 格式：PNG RGBA，圆形，圆外透明，边缘已抗锯齿。代码里不用再做圆形裁切，直接按 alpha 贴图。
- 来源：2026-10-13 用 Notion AI 图像生成功能生成，仿照《严格参考图》的头像风格，供本项目使用。
- 加载：`include_bytes!` 内嵌，用工作区已有的 `png` crate 解码成 `tiny_skia::Pixmap`。
